## Overview

As Lead Lab Programmer at NEATLABs (Neural Engineering and Translation Labs) from 2017-2022, I developed computational methods for analyzing neural dynamics and their relationship to behavior.

## Research Focus

Our work centered on understanding how neural oscillations encode information about the environment and guide behavior. Key areas included:

### Default Mode Network Dynamics

Investigated electrophysiological correlates of the default mode network in rodents, contributing to a publication in *Cerebral Cortex Communications*.

### Reward Learning and Oscillations

Studied how beta and high-gamma oscillations in cortico-striatal circuits encode learned reward value, published in the *Journal of Neuroscience*.

### Multi-Site Recording Methods

Co-authored methods papers on low-cost probe designs for chronic multi-site recordings, enabling broader adoption of sophisticated recording techniques.

## Technical Contributions

### Analysis Infrastructure

- Built Python-based analysis pipelines for LFP signal processing
- Developed automated artifact detection and removal systems
- Created visualization tools for multi-channel neural data

### Signal Processing Methods

- Implemented time-frequency decomposition methods (wavelets, multitaper)
- Built cross-frequency coupling analysis tools
- Developed template matching for behavioral state classification

### Data Management

- Established lab data organization standards
- Built versioned analysis pipelines for reproducibility
- Created documentation systems for methods and results

## Publications

This work contributed to three peer-reviewed publications:

1. **Cerebral Cortex Communications (2021)**: Rodent DMN electrophysiology
2. **Frontiers in Psychiatry (2021)**: Multi-site probe designs
3. **Journal of Neuroscience (2025)**: Cortico-striatal oscillations

## Impact

The methods and infrastructure developed during this period continue to support ongoing research at NEATLABs and have been adopted by collaborating labs.
