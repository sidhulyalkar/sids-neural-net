# Sid’s Neural Net: Project Context Pack

This context pack is designed to feed directly into Claude Code or another coding agent building **Sid’s Neural Net**, a dynamic personal website and research atlas for Sidharth Hulyalkar.

The goal is to preserve the full dimensionality of Sid’s work: not only public GitHub repositories and publications, but also private/professional DataJoint work, lab systems, old creative hardware projects, unpublished research directions, and life/personality nodes.

Recommended use:
- Put these files under `content/context/` or `data/manual/project-context/`.
- Convert each file into one or more `NeuralNode` records.
- Link each project node to skills, organizations, technologies, publications, and timeline events.
- Use `importance`, `visibility`, and `audience` metadata to decide what appears in Recruiter View, Research View, Full Brain View, and Personal View.

Suggested display modes:
- **Recruiter View:** DataJoint, publications, Panoptic/AI product work, public technical projects.
- **Research View:** NEATLABs, publications, DTW/TCA, neural augmentation, neuroFMx, mechanistic interpretability.
- **Builder View:** DataJoint cloud templates, monitoring tools, hardware/RasPi projects, BCI/real-time systems.
- **Full Brain View:** everything, including older class projects, creative LED/audio experiments, Shasta/adventure/personality nodes.
