# Research cave figures

These are lossless crops rendered from the publication PDFs already hosted in this repository. The complete figures and original labels are preserved, with a title, authors/year and figure number on the cave plaque. Clicking opens the source PDF at the relevant page.

- `cortico-striatal-beta-oscillations-2024.webp`: Figure 2, PDF page 9.
- `mapping-large-scale-networks-2021.webp`: Figure 1, PDF page 4.
- `chronic-multisite-probe-designs-2021.webp`: Figure 7, PDF page 15.

Render procedure: PyMuPDF, 2.5x page scale, clipped to the figure image bounds, lossless WebP. No scientific labels or values were altered. Original author/publisher attribution and reuse notices remain in the linked source papers.
